# Maison Séléné — Haute Gastronomie • Celestial Brasserie 🍷☽✨

A world-class luxury web experience for **Maison Séléné**, an esteemed haute brasserie crafting celestial gastronomy, wood-fired prime cuts, artisanal hand-rolled pasta, and rare grand cru vintages in an enchanting moonlit ambiance.

![Maison Séléné Preview](https://images.unsplash.com/photo-1476224203421-9ac39bcb3327?w=1200&q=80)

---

## 🌟 Key Features

- **Interactive Gastronomic Menu**:
  - Filterable category architecture: *Entrées & Starters, Plats Principaux, Chef's Reserve & Wood-Fired, Desserts & Douceurs, Artisanal Elixirs & Grands Crus*.
  - Dish cards with high-resolution photography, culinary descriptions, dietary badges (`GF`, `Vegetarian`, `Raw Bar`, `Shellfish`), and curated Sommelier pairing notes.
  - Direct "Reserve with this Dish" actions that pre-note reservations.
- **Prestige Tasting Menu Showcase**:
  - Featured presentation of Executive Chef Julian Vance's 5-Course Celestial Tasting Experience (₹14,500 / guest, with optional Grand Cru wine pairing +₹7,500).
  - One-click reservation pre-selection linking directly to the concierge booking suite.
- **Atmospheric Hero Motion Showcase**:
  - Multi-slide atmospheric hero slider with directional controls, pagination dots, touch swipe gesture support, and fluid Ken Burns transitions.
- **Social Moments Gallery**:
  - Curated reels and Instagram photography with interactive metrics and dynamic engagement hover veils.
- **Interactive Reservation Suite**:
  - Concierge booking system with validation, service hours verification, party sizing, and dining experience preference selectors.
- **Fixed Glassmorphism Header & Ergonomic Mobile Drawer**:
  - Dynamic scroll blur transitions, scroll-spy link tracking, and mobile drawer menu navigation.
- **High-End Editorial Design System**:
  - Sophisticated typography pairing `Playfair Display`, `Dancing Script`, and `Inter` on an emerald obsidian and champagne gold palette.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible structure with microdata and SEO tags.
- **CSS3**: Custom design tokens, glassmorphism, responsive CSS grid & flexbox, smooth cubic-bezier transitions.
- **JavaScript (Vanilla ES6+)**: Modular interaction logic, touch ergonomics, and category filtering without heavy third-party framework overhead.

## 🚀 Getting Started

Simply open `index.html` in any modern browser:

```bash
# Clone the repository
git clone https://github.com/HimanshuGehlot18/la-melrose-restaurant.git

# Navigate into project directory
cd lunar-restaurant

# Open directly or run a lightweight local dev server (e.g. VS Code Live Server, serve, or Vite)
npx serve .
```
